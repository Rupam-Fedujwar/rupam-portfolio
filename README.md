# Rupam Fedujwar - Professional Portfolio Website

A modern, responsive multi-page website showcasing the academic and professional portfolio of Anuj Nautiyal, Research Scholar in Transportation Engineering at IIT Roorkee.

## 🌟 Features

- **Multi-page Architecture**: Separate pages for different sections
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Navigation**: Sticky navbar with mobile hamburger menu
- **Contact Form**: Functional contact form with email integration
- **Project Showcase**: Detailed project pages with technology tags
- **Social Integration**: Links to academic and professional profiles

## 📁 File Structure

```
website/
├── index.html          # Homepage with hero section and overview
├── about.html           # About page with detailed bio
├── projects.html        # Projects showcase page
├── contact.html         # Contact page with form
├── styles.css          # Complete CSS styling
├── script.js           # JavaScript functionality
├── README.md           # This file
└── profile.jpg         # Profile image (add this)
```

## 🚀 Getting Started

1. **Add Profile Image**: Place your profile picture as `profile.jpg` in the website folder
2. **Open in Browser**: Simply open `index.html` in any web browser
3. **Navigate**: Use the navigation menu to explore different pages

## 🔧 Customization

### Updating Content
- **Personal Info**: Update text content in HTML files
- **Projects**: Modify project details in `projects.html`
- **Contact**: Update contact information in `contact.html`
- **Styling**: Modify colors and layout in `styles.css`

### Color Customization
Edit CSS variables at the top of `styles.css`:
```css
:root {
    --primary-color: #2c3e50;
    --secondary-color: #3498db;
    --accent-color: #e74c3c;
    /* ... other variables */
}
```

### Adding New Pages
1. Create new HTML file
2. Add to navigation menu in all existing pages
3. Update active state logic in `script.js`
